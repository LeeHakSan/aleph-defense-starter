1~12단계 공격 점검 실측표

위 점검 수치는 이 표의 줄 수와 결과만 센 것이며, 쓰기 요청이 필요해 보내지 않은 줄은 미실행입니다. 제출 묶음(npm run bundle)과 같은 점검 목록을 같은 코드로 보낸 읽기 요청(GET)의 결과입니다. 한 줄은 요청 하나입니다. 6~9단계 규칙 줄은 서버가 고정된 가상 입력으로 판정기·탐지 규칙을 실행한 응답이며 실제 사용자·기기 상태가 아닙니다. 요청 ID 는 응답의 서버 요청 번호(Vercel 기록의 Request ID 와 같음)이고, 확인 시각은 그 요청을 보낸 시각입니다.
